Every print, costed and kept.

Print Tally keeps a permanent record of every print from your imagePROGRAF: the ink used on each channel, the paper, the size and when it was printed. Record what you paid for paper and ink, and it works out what each print cost.

Why it exists · macOS 27

Canon’s Accounting Manager doesn’t run on macOS 27. Print Tally doesn’t need it.

Print Tally reads the job history directly from the printer over the network, so no Canon software is needed. And where the printer forgets, Print Tally doesn’t.

Web and desktop

One ledger. In the browser or on the Mac, equally.

Both run the same Print Tally and show the same screens. Pick whichever suits the computer in front of you.

Web

Run one command.

bunx printtally starts Print Tally and opens it in your browser. It needs Bun 1.3.9 or newer.

bunx printtally
localhost:4318/jobs
Desktop

Or open the Mac app.

For Macs with Apple silicon. It includes everything it needs, so there’s no Bun to install. It runs its own backend, or connects to the computer next to the printer.

Download the .dmgOpen it, drag Print Tally to Applications.
Other devices

From the iPad, the phone, the laptop.

Keep Print Tally running on a computer that stays near the printer, and check a print’s cost from wherever you are.

  1. On that computer, run printtally serve --host.
  2. Make a single-use pairing link or QR code for each device with printtally pair.
  3. Open it on the device. It works over Tailscale, too. The desktop app can connect to that computer in the same way.

Setup

Three steps, then your jobs appear.

You need the printer on your network with a fixed IP address, and its administrator password. The desktop app and bunx printtally both open on this same setup screen.

From then on, Print Tally collects on its own.
